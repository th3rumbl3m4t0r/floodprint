This is a tool meant to aid DDoS mitigation. Drop in a PCAP that is at least 50% attack traffic and this will try to find common substrings and generate PCRE regexes with adjustable aggressvity with targeting 50-90% of the pcap. For more messy attacks there is the multi-vector mode which will take top port+proto combinations and run the same logic. All is outputed into a single PCRE regex
